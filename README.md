# Ukraine Atlas

Interactive 3D map of Ukraine's 27 regions with live air-raid alerts, plus views for night lights from space, the front line, refugees and aid, and Black Sea shipping.

Live site: https://w1zman.github.io/ukraine-atlas/

Data: Natural Earth (boundaries), alerts.in.ua (alerts), NASA GIBS (night lights), DeepState via cyterat/deepstate-map-data (occupied areas), UNHCR, Eurostat, IOM, UDI, Kiel Institute, and news reports listed on each view. Not an official warning system.
